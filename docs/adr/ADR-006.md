# ADR-006 — Grade Audit History

## Status

Zaakceptowany — decyzja technologiczna lub zasada narzucona w briefie; realizacja PLANNED. Data: 2026-11-15. Otwarte decyzje (hosting, produkcyjna retencja, plusy/minusy) nie są przez ten ADR akceptowane.

## Kontekst

Każde utworzenie, zmiana i usunięcie musi pozostać czytelne.

## Decyzja

Soft delete grades/users, append-only grade_audits z snapshotami, aktorem, czasem i wersją; jedna transakcja.

## Uzasadnienie

Audyt nie może zniknąć razem z oceną ani być zapisany po nieudanym commicie.

## Rozważone alternatywy

Hard delete + cascade, event-only audit, asynchroniczny audyt — odrzucone.

## Konsekwencje

Brak restore/purge endpointów; version zapobiega lost update; PII retencja przed produkcją pozostaje otwarta.

## Ryzyka

Przyrost danych i obejście serwisu; uprawnienia DB i code review.

Szczegóły normatywne: [dokument źródłowy](../database/BUSINESS_RULES.md). Zmiana istotnego zachowania wymaga aktualizacji tego ADR i powiązanych kontraktów/specyfikacji.
