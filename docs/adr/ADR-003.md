# ADR-003 — Tailwind CSS + shadcn/ui

## Status

Zaakceptowany — decyzja technologiczna lub zasada narzucona w briefie; realizacja PLANNED. Data: 2026-11-15. Otwarte decyzje (hosting, produkcyjna retencja, plusy/minusy) nie są przez ten ADR akceptowane.

## Kontekst

Figma ma własny system wizualny i komponenty.

## Decyzja

Tailwind 4 + semantic CSS variables; shadcn/Radix dostosowane do Figmy.

## Uzasadnienie

Utility styling i dostępne zachowania bez narzucania generycznego wyglądu.

## Rozważone alternatywy

MUI/Bootstrap/CSS-in-JS — odrzucone; CSS globalny tylko tokeny/fonty/uzasadnione wyjątki.

## Konsekwencje

Public Sans, role kolorów i warianty z MCP; brak instalacji całej biblioteki.

## Ryzyka

Domyślny theme shadcn może zastąpić design; wymagane porównanie.

Szczegóły normatywne: [dokument źródłowy](../design/DESIGN_SYSTEM.md). Zmiana istotnego zachowania wymaga aktualizacji tego ADR i powiązanych kontraktów/specyfikacji.
