# ADR-004 — MariaDB and Eloquent

## Status

Zaakceptowany — decyzja technologiczna lub zasada narzucona w briefie; realizacja PLANNED. Data: 2026-11-15. Otwarte decyzje (hosting, produkcyjna retencja, plusy/minusy) nie są przez ten ADR akceptowane.

## Kontekst

Wymaganie akademickie relacyjnej MariaDB i historycznych ocen.

## Decyzja

MariaDB 11.4/InnoDB + Eloquent, migracje, FK/CHECK/unique; bez Repository dla każdego modelu.

## Uzasadnienie

Jeden trwały model danych i atomowe transakcje.

## Rozważone alternatywy

SQLite runtime, NoSQL, osobna baza audytu — odrzucone.

## Konsekwencje

Testy integracyjne na MariaDB; constraints i reguły przekrojowe uzupełniają się.

## Ryzyka

Same FK nie sprawdzą zgodności kontekstu; usługi blokują i testują relacje.

Szczegóły normatywne: [dokument źródłowy](../database/SCHEMA.md). Zmiana istotnego zachowania wymaga aktualizacji tego ADR i powiązanych kontraktów/specyfikacji.
