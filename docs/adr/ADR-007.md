# ADR-007 — Figma as Design Source

## Status

Zaakceptowany — decyzja technologiczna lub zasada narzucona w briefie; realizacja PLANNED. Data: 2026-11-15. Otwarte decyzje (hosting, produkcyjna retencja, plusy/minusy) nie są przez ten ADR akceptowane.

## Kontekst

Istnieje pełny plik z koncepcją A, stanami i mobile.

## Decyzja

Wygląd z całego pliku QmOrJFZWMpJTHC5Q8s7Ltp; funkcje i bezpieczeństwo z dokumentacji.

## Uzasadnienie

Zachowujemy spójność wizualną, nie kopiujemy nieaktualnych notatek backendu.

## Rozważone alternatywy

Generyczny template, koncepcja B, interpretacja tylko jednej ramki — odrzucone.

## Konsekwencje

Każdy UI feature odczytuje właściwe node IDs; jawne luki i adaptacje.

## Ryzyka

Zmiana ID, brak admin grade frames; bez fikcyjnego VERIFIED i bez omijania funkcji.
