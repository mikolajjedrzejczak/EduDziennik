# ADR-009 — GitHub Actions CI/CD

## Status

Zaakceptowany — decyzja technologiczna lub zasada narzucona w briefie; realizacja PLANNED. Data: 2026-11-15. Otwarte decyzje (hosting, produkcyjna retencja, plusy/minusy) nie są przez ten ADR akceptowane.

## Kontekst

Projekt wymaga automatycznej kontroli jakości, ale hosting nie jest podany.

## Decyzja

GitHub Actions frontend/backend/E2E i docs-only path; CD jako plan do wskazania środowiska.

## Uzasadnienie

Sprawdzalne PR i brak fikcyjnego deployu.

## Rozważone alternatywy

Ręczne testy jako jedyna bramka lub pełne E2E każdej zmiany docs — odrzucone.

## Konsekwencje

Required aggregate check; artefakt po SHA, backup i smoke przed release.

## Ryzyka

Pominięte required checks, dostęp sekretów z PR; minimalne permissions.

Szczegóły normatywne: [dokument źródłowy](../infrastructure/CI_CD.md). Zmiana istotnego zachowania wymaga aktualizacji tego ADR i powiązanych kontraktów/specyfikacji.
