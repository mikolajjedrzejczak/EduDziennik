# ADR-008 — Docker Environment

## Status

Zaakceptowany — decyzja technologiczna lub zasada narzucona w briefie; realizacja F-002 zweryfikowana lokalnie, do przeglądu (raport w specyfikacji F-002). Data: 2026-11-15. Otwarte decyzje (hosting, produkcyjna retencja, plusy/minusy) nie są przez ten ADR akceptowane.

## Kontekst

Środowisko ma działać bez lokalnego PHP/MariaDB.

## Decyzja

Compose z nginx/app/node/db; Node tylko dev/build; trwały db_data.

## Uzasadnienie

Odtwarzalne lokalne środowisko i zbliżony runtime CI.

## Rozważone alternatywy

Instalacja usług na hoście, Kubernetes, Redis — odrzucone.

## Konsekwencje

Bootstrap i migracje jawne; obrazy przypięte, sekrety poza repo.

## Ryzyka

Permisje wolumenów, cold start i utrata danych przez down -v; test F-002.

Szczegóły normatywne: [dokument źródłowy](../infrastructure/DOCKER.md). Zmiana istotnego zachowania wymaga aktualizacji tego ADR i powiązanych kontraktów/specyfikacji.
