# ADR-002 — Laravel + Inertia + React

## Status

Zaakceptowany — decyzja technologiczna lub zasada narzucona w briefie; realizacja PLANNED. Data: 2026-11-15. Otwarte decyzje (hosting, produkcyjna retencja, plusy/minusy) nie są przez ten ADR akceptowane.

## Kontekst

Wymagane MVC i interaktywny React bez osobnego API.

## Decyzja

Laravel 13/PHP 8.3, Inertia 3, React 19; routing i sesje w Laravel.

## Uzasadnienie

React jest View, Eloquent Model, kontrolery orkiestrują; Inertia eliminuje dublowanie routingu.

## Rozważone alternatywy

Blade-only i SPA REST — odrzucone przez zatwierdzony stack.

## Konsekwencje

Formularze useForm, redirect/session errors, jawne DTO.

## Ryzyka

Przeniesienie reguł do JS i błędne422 JSON; kontrakty i testy chronią przepływ.

Szczegóły normatywne: [dokument źródłowy](../http/REQUESTS_RESPONSES.md). Zmiana istotnego zachowania wymaga aktualizacji tego ADR i powiązanych kontraktów/specyfikacji.
