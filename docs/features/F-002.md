## 22. Raport realizacji 2026-11-15

FACT: dodano compose.yaml (nginx/app/node/db), obrazy PHP i Node, konfigurację Nginx/FPM, healthchecks, named volumes vendor/node_modules/db_data, bootstrap i operatorski test infrastruktury. Nie dodano zależności pakietowych ani migracji produktu. Nie publikowano dokumentacji ani nie zmieniano issue w GitHub.

DECISION: `/up` obsługuje HealthController poza middleware sesji i sprawdza `SELECT 1` bez wymagania tabel. Kontroler zwraca 503 bez surowych szczegółów połączenia także w trybie debug; w zainstalowanym Laravel health frameworka zwracał 500, niezgodnie z kontraktem projektu. MariaDB ma timeout połączenia 3 s. Kontener PHP ma memory_limit=512M, ponieważ PHPStan osiągnął limit domyślnego obrazu 128M.

DECISION: Node nie zawiera PHP. Compose wyłącza generator Wayfinder w pluginie Vite przez WAYFINDER_EXTERNAL; bootstrap generuje typy przez app. Po zmianie tras operator ponawia `docker compose exec app composer wayfinder`. Migracje i seedy pozostają jawne, poza bootstrapem i restartem. Baza fixture testu jest oddzielona od aplikacji i tworzona tylko na czas testu; tabela powstaje przez migrację testową.
