# F-204 — Grade Creation

## 1. Status

Planned

## 2. Priorytet

P0

## 3. Cel

Wystawić ocenę w autoryzowanej komórce.

## 4. Historia użytkownika

Jako nauczyciel; współdzielony zakres także dla pozostałych uprawnionych ról chcę wystawić ocenę w autoryzowanej komórce, aby móc bezpiecznie realizować zadania dziennika.

## 5. Zakres

Create teacher/admin, istniejący assessment lub najpierw jego utworzenie w F-203; bez batch.

## 6. Zależności

[F-203](F-203.md), [F-402](F-402.md)

## 7. Odniesienia Figma

[18:542](https://www.figma.com/design/QmOrJFZWMpJTHC5Q8s7Ltp?node-id=18-542); [23:796](https://www.figma.com/design/QmOrJFZWMpJTHC5Q8s7Ltp?node-id=23-796); [18:927](https://www.figma.com/design/QmOrJFZWMpJTHC5Q8s7Ltp?node-id=18-927); [23:1254](https://www.figma.com/design/QmOrJFZWMpJTHC5Q8s7Ltp?node-id=23-1254) Mapowanie wariantów ról i jawne luki: [SCREEN_MAP](../design/SCREEN_MAP.md); referencja współdzielona nie oznacza dedykowanej ramki admina.

## 8. Uprawnienia

Wymagany zakres [RBAC](../product/RBAC.md): S dla ucznia, T dla nauczyciela, pełny zakres admina; każda mutacja ocen dodatkowo W. Dla elementów wspólnych rola nie zastępuje Policy rekordu.

## 9. Reguły biznesowe

GradeService + audyt create w jednej transakcji; issued_by z sesji; snapshot wartości kolumny. Szczegóły: [reguły domenowe](../database/BUSINESS_RULES.md).

## 10. Baza danych

grades i grade_audits; kontekst istniejącego assessment/enrollment. Zmiany tylko migracjami.

## 11. Implementacja Laravel

Admin/GradeController@create; Admin/GradeController@store; Teacher/GradeController@create; Teacher/GradeController@store [Pełne trasy](../http/ROUTES.md).

## 12. Kontrakt Inertia

redirect role.gradebooks.show; shared/grades/create; GradeFormProps [Typy i redirecty](../http/REQUESTS_RESPONSES.md).

## 13. Implementacja React

Strony zgodnie z kontraktem powyżej; komponenty z [COMPONENTS](../design/COMPONENTS.md), useForm dla mutacji, URL dla filtrów. Nie powielać serwisów domenowych w React.

## 14. Tailwind / UI

Semantyczne tokeny [DESIGN_SYSTEM](../design/DESIGN_SYSTEM.md), mobile 390/tablet 1024/desktop 1440 według [RESPONSIVENESS](../design/RESPONSIVENESS.md); stany pending/error/empty i fokus.

## 15. Walidacja

GradeFormContextRequest, StoreGradeRequest — reguły pól w [kontrakcie](../http/REQUESTS_RESPONSES.md).

## 16. Obsługa błędów

[ERROR_HANDLING](../http/ERROR_HANDLING.md): błąd zakresu403/404, walidacja przez redirect/errors; brak częściowego zapisu i automatycznego ponawiania mutacji.

## 17. Przypadki brzegowe

Duplikat submit, teacher wycofany podczas formularza, uczeń przeniesiony, waga5.

## 18. Bezpieczeństwo

Serwer ponownie sprawdza zakres, także przy bezpośrednim żądaniu. Props tylko z allowlisty; brak haseł i danych obcych kont. Nie ufać can ani hidden input.

## 19. Kryteria akceptacji

**Mając** wymagane zależności i dane testowe, **gdy** wykonano funkcję w opisanym zakresie, **wtedy**: Dla aktywnego przypisania zapis tworzy1 grade i1 audit; błąd insertu audit cofa oba; waga6 odrzucona.

**Mając** błędny kontekst lub dane, **gdy** operacja zostanie podjęta, **wtedy** brak nieautoryzowanego efektu i komunikat zgodny z sekcją błędów.

## 20. Testy

PHPUnit transaction rollback/permissions/validation; E2E teacher→student sees grade.

## 21. Definition of Done

Kryteria z sekcji19 udowodnione testami, zależności działają, dokumentacja/kontrakty aktualne; [wspólne DoD](../testing/DEFINITION_OF_DONE.md). Dla brakujących ramek nie deklarować pełnej zgodności wizualnej; rozstrzygnąć lukę przed Done.
