## 22. Realizacja — 2026-11-16

FACT: `Admin/DashboardController@index` przyjmuje wspólny `DashboardFilterRequest` i przekazuje allowlistowane `AdminDashboardProps`. `AdminDashboard` autoryzuje odczyty przez User/SchoolClass/Subject/GradeAudit Policies przed agregacją; rola admin jest również wymuszana przez middleware. Brak mutacji i migracji w tej funkcji.

FACT: `userCounts` obejmuje wszystkie nieusunięte konta według roli (również nieaktywne), `inactiveCount` jest ich nieaktywnym podzbiorem. `subjectCount` obejmuje nieusunięty słownik szkoły. `classCount` obejmuje nieusunięte klasy roku wybranego termu. Brak przydziałów nie blokuje administratorowi konfiguracji okresu ani odczytu.

FACT: domyślny term obejmuje dziś Europe/Warsaw; poza takim termem UI wymaga jawnego wyboru. Bez termu konta/przedmioty nadal mają rzeczywiste liczniki, klasy mają `classCount=0` i „—” w UI, a `recentAudits=[]`. Nie wybieramy losowego okresu. Niepoprawny term i zabronione student_id/student_enrollment_id →303 z zachowaniem poprawnych filtrów i session errors; obce parametry nie zmieniają zakresu.

FACT: maksymalnie pięć audytów ocen wybranego termu, sort `occurred_at DESC, id DESC`. Odczyt zachowuje soft-deleted oceny, kolumny, przedmioty, uczniów i autorów. Wspólny `AuditPresenter` obsługuje pulpit i historię; snapshoty mają allowlistę F-104. Brak emaili, haseł i pełnych modeli w audytach.

VERIFIED: odczytano Figma MCP design context i screenshoty desktop19:2, mobile24:2 i wskazany w dokumentacji tablet38:13515. Ostatni node przedstawia **listę użytkowników**, nie pulpit; 1024px to adaptacja według reguł responsywności i istniejącej powłoki F-007.

DECISION: zachowano tokeny, Public Sans, grupę czterech liczników, tabelę desktop, układ mobile 2×2, kolejność „stan kont → audyty” na mobile i dwie kolumny na desktop. Dodano selektor semestru wymagany kontraktem. Sekcja „Ostatnie operacje w systemie” została zawężona i nazwana „Ostatnie zmiany ocen”; MVP nie audytuje operacji kont. Nie odtwarzano fikcyjnych blokad logowania, nieaktywowania po siedmiu dniach ani braku nauczyciela konkretnego przedmiotu. „Stan kont” pokazuje rzeczywisty inactiveCount oraz link do listy `status=inactive`. Nie pokazujemy liczby nauczycieli z przydziałami, której kontrakt nie zawiera. Te różnice i zastana powłoka F-007 wykluczają deklarację zgodności 1:1 z Figmą.

FACT: testy F-301 dodano w `tests/Feature/Admin/AdminDashboardTest.php`, `tests/Frontend/admin-dashboard.test.tsx` i `tests/Browser/admin-dashboard.spec.ts`. Fixture przeglądarkowe sprawdza izolację bazy przed migracjami i korzysta z GradeFactory/GradeService tworzących rzeczywiste audyty.
