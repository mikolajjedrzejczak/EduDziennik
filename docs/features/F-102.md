## 22. Stan implementacji

FACT: `GET /student/grades` (`student.grades.index`, `role:student`) → `Student\GradeController@index`, strona `student/grades/index`, pozycja „Moje oceny” w menu serwerowym ucznia. Zapytania zawsze startują od `Grade::visibleTo($student)` (usunięte oceny wyłączone, zakończony enrollment nadal czytelny); `GradeFilterRequest` (wspólna nazwa z kontraktu, F-102 wdraża zakres ucznia): `term_id`, `subject_id`, `category_id` muszą należeć do widocznych danych ucznia, `q` ≤100 (temat, LIKE z escapowaniem), `date_from/date_to` (`Y-m-d`, from ≤ to), `page`, `per_page` 10/25/50, `sort` `graded_on|value|weight`, `direction`; `student_id` i `student_enrollment_id` są `prohibited`. Błędny parametr → 303 na tę samą trasę bez niego + `errors`; strona poza końcem → 303 na ostatnią stronę z zachowaniem filtrów. Kontrakt: [stan integracji F-102](../http/REQUESTS_RESPONSES.md#stan-integracji-f-102).

DECISION: brak `term_id` → bieżący semestr (data Europe/Warsaw) spośród semestrów lat szkolnych, w których uczeń ma/miał zapis; w przeciwnym razie ostatni rozpoczęty, a bez zapisów pusty stan „Brak semestru”. Średnia i licznik (`GradeSummary::aggregate`, SQL DECIMAL, half-up) liczone są z tego samego zapytania co lista, **bez** paginacji; filtry (przedmiot, kategoria, daty, temat) zawężają je, a `summary.scopeLabel` nazywa zakres w UI. `subjects[]` (rozszerzenie `GradeListProps`) to średnie i liczniki przedmiotów semestru z filtrami poza przedmiotem — lewa lista z Figmy 14:154.

DECISION (adaptacja Figmy): desktop/tablet — lista przedmiotów + tabela ocen + objaśnienie średniej (14:154); mobile — filtr semestru i panel „Więcej filtrów”, oceny jako karty (21:76/21:284 pokazują chipy semestru i „Cały rok”: „Cały rok” poza zakresem, bo `term_id` jest pojedynczy). Link „Szczegóły” i „zmieniona” z ramki dojdą z F-103/F-104 (brak tras); `GradeDTO.can` jest w całości `false` (uczeń nie mutuje, historia = F-104). Nie ma ramki tabletu 1024 dla tego ekranu — układ dziedziczy desktop z zwężoną siatką.

Kontrole (Docker PHP 8.3 + MariaDB 11.4, Node 22): PHPUnit 281 pass (w tym `StudentGradesTest`: własność, średnia niezależna od strony, filtry, obce ID, strona poza końcem, zakończony enrollment, role), Vitest (w tym `student-grades.test.tsx`: lista, empty/no-results, brak semestru, filtry URL bez właściciela), Playwright `student-grades.spec.ts` 4/4 (390/1024/1440 px bez poziomego scrolla, filtr, empty, odrzucenie `student_id`, 403 dla `/admin`), Pint, PHPStan, ESLint, Prettier, `tsc --noEmit`, `vite build`. Porównanie wizualne: zrzut 1440 px zgodny z 14:154 (układ, tokeny, chipy), mobile 390 świadomie uproszczony (powyżej). NIE wykonano: ręcznego testu czytnikiem ekranu, osobnego przeglądu tabletu.
